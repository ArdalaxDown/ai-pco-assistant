# 🤖 Local AI Digital Clone (Privacy-First LLM Assistant)

## 📌 Overview
An advanced, locally hosted AI assistant engineered to operate entirely off-grid. By leveraging open-source Large Language Models (LLMs) and custom `Modelfiles`, this project functions as a highly specialized digital clone. It bypasses standard cloud API restrictions, offering a fully customizable, private, and unrestricted environment for operational queries and task execution.

## 🚀 Key Features
* **100% Local Execution:** Runs completely on local hardware without internet dependency or third-party API costs, ensuring absolute data privacy for sensitive operational data.
* **Unrestricted System Prompting:** Built with custom logic that gives the user full control over the AI's behavior, personality, and response generation, free from standard commercial API guardrails.
* **Multimodal Capabilities (Vision):** Integrates the `LLaVA` model architecture to process and analyze images and visual data locally.
* **Specialized Persona (PCO Engineer):** Configured to emulate the analytical and technical thinking of a Railway Operations Control (PCO) Engineer.

## 🛠️ Tech Stack & Architecture
* **Language:** Python 3.x
* **AI Engine:** Ollama (Local LLM orchestration)
* **Models Used:** Custom Llama-based weights and LLaVA (Large Language-and-Vision Assistant)
* **Configuration:** Custom `Modelfile` scripting for precise role-prompting and parameter tuning (temperature, context window).

## 💡 Engineering Value & Use Case
Running LLMs in the cloud exposes proprietary data and limits customization. This project demonstrates the ability to deploy **Privacy-First, Unrestricted AI pipelines**.
